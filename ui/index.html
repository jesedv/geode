Hyper-Catalan series solver for univariate polynomials

Exact-rational closed-form solutions (via Hyper-Catalan series). Produce rational expressions, truncate for approximations, and export results as LaTeX.

Use cases

  • Game physics: cloth, curve intersections
  • Computer graphics: polynomial surfaces
  • Symbolic CAS integrations

Open source

Free MIT license. Contributions welcome — open issues and PRs on GitHub.

Quick start

  1. Clone: git clone https://github.com/<your-user>/geode.git
  2. Run tests: cargo test --workspace
  3. Serve UI: cd ui && npx serve . then open http://localhost:5000
