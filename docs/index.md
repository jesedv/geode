# Geode — Hyper-Catalan Polynomial Solver

Geode solves univariate polynomials (including quintics and higher) using the Hyper-Catalan series method producing exact rational expressions (truncated for approximation).

Features
- Exact rational arithmetic
- WASM + Rust core
- UI to input polynomials and test solutions online

Get started
1. Clone: git clone https://github.com/<your-user>/geode.git
2. Build: cargo test
3. UI: cd ui && npx serve .
